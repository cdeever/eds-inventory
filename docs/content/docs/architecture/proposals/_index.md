# Proposals

Ideas the inventory expects to build on but has not decided. A proposal
says what the idea is, why it would help, where its smallest useful version
stops, and what is still open. It is not part of the
[decision log](../decisions/): nothing here is settled, and nothing here is
built yet.

When a proposal is accepted, its versions are planned, and an ADR records
each decision it needs; the proposal links to them.

The idea of the inventory itself was proposed in EdS
([A Music Inventory](https://cdeever.github.io/eds/docs/architecture/proposals/music-inventory/)).
